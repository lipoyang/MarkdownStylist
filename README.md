# MarkdownにCSSを適用したHTMLを生成する簡易ツール

Pythonで動作する簡易的なGUIツールです。

一般的に、Markdown記法を用いるCMSサイトではセキュリティ上の理由から `<style>`要素を記事に使用しても無効化されます。このツールを使えば、CMSに貼り付け可能なHTMLを生成できます。

## (1) dlpp.py
ProtoPediaの記事のMarkdownをファイル保存する補助ツールです。

ProtoPediaの作品ページ（例えば https://protopedia.net/prototype/8534 ）の作品番号 (8534) を指定すると、そのページから「システム構成」と「ストーリー」の Markdown をファイルに保存します。ファイル名は、作品番号＋"_A.md" および 作品番号＋"_B.md" となります。 (例：8534_A.md, 8534_B.md) 　ただし、記事が一般公開されている必要があります。

### 依存ライブラリのインストール
```bash
pip install requests beautifulsoup4
```

## (2) mdstyle.py
MarkdownにCSSを適用する簡易ツールです。

指定したMarkdownファイルから、見出し行 `#`, `##`, ... `######` をHTMLの見出し`<h1>`, `<h2>`, ... `<h6>` 要素に変換し、指定したCSSファイルのスタイルを使用します。スタイルは個々の見出し要素のタグに `style=` の形で記述します。

また、`>` で始まる引用文をHTMLの`<blockquote>`要素に変換し、指定したCSSファイルのスタイルを使用します。スタイルは個々の`<blockquote>`要素のタグに `style=` の形で記述します。

また、`![代替テキスト](画像ファイル名)` の形式の画像貼り付けをHTMLの`<img>`要素に変換し、横幅を指定できるようにします。横幅は、`![代替テキスト](hoge.png#400)`のように、ファイル名の後に `#`+横幅ピクセル数 の形で指定します。(このツールで変換しない場合、`#`以降の文字列はフラグメントと見なされ無視されるので、互換性を保てます。これはトリックです。)

### 依存ライブラリのインストール
```bash
pip install tinycss2 tkinterdnd2
```
